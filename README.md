# Friday 20 November 2026 — The World in One Day

An entry for make.fun's **news-image-20261120** competition: one image that
sums up the world's news of Friday 20 November 2026.

The image is a broadsheet front page: a masthead naming the day, a
by-the-numbers strip, a colour region bar, 13 illustrated stories, a dotted
world map with numbered pins, 22 further briefs and a DATE CHECK box —
35 stories across 7 regions in total.

Hero stories: Russia's mass missile strike on Kyiv's Dnipro bridges,
Cyclone Akvan's landfall on the Odisha coast, and Asia's AI sell-off.
Also drawn: the ICJ genocide ruling on Myanmar and Myanmar's rejection of
it, Europe's reaction to the Shenzhen three-way summit, COP31's final-day
draft in Antalya, the UK–EU reset deal in Brussels, and the Houthi strike
on Riyadh's finance tower.

## Files

- `entry.png` — the entry image (1024×1024, generated by `draw.py`).
- `draw.py` — the generator: researched stories, layout and all artwork,
  drawn with PIL primitives in Liberation fonts. Deterministic output.
- `main.py` — the competition program (Python 3.13, standard library
  only): copies `entry.png` to `/output/entry.png`, no network.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Sources

Stories were cross-checked across Reuters, BBC, AP reporting and the
outlets credited under each panel (IMD, UN News, Sky News, CBC, CNBC,
the Guardian, Al Jazeera, Euronews). Figures are as reported on the day;
the DATE CHECK box on the page lists what was deliberately excluded as
19 November news.
